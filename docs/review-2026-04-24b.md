## High

### [ui-ux] No confirmation on quote Accept / Decline buttons
`app/views/clients/quotes/show.html.haml`
`app/views/clients/quotes/index.html.haml`
`app/views/clients/jobs/show.html.haml`

Accept and Decline are POST buttons with no `turbo_confirm`. One stray click
accepts/declines a quote with no undo. "Cancel request" already has a confirm —
these should too.

---

### [bug/ui-ux] shop_selector submit not disabled when 0 shops selected
`app/javascript/controllers/shop_selector_controller.js`

Button text updates ("Send request to 0 shops") but `disabled` is never set on
count === 0. User can submit an empty request to the server.

## Medium

### [ui-ux] Quote form shows empty member select with no guidance
`app/views/shop_admin/quotes/new.html.haml`

If the shop has no active enrolled members, the select shows "— Select member —"
with nothing below. No link to the Members page, no explanation. Shop owner is stuck.

---

### [ui-ux] Form submit buttons have no loading / disable-on-click
Multiple forms across the app (quote new, registration, invite member).
Slow network or double-click sends the request twice. Rails' `disable_with` is not set.

---

### [ui-ux] "Load earlier messages" doesn't scroll to new messages
`app/views/shared/_job_chat.html.haml`

After clicking "Load X earlier messages", full page reloads but viewport stays at
top. User has no indication that messages loaded. Should scroll to chat or use anchor.

---

## Low

### [ui-ux] Client confirmation form shows editable hours — no cue that it affects invoice
`app/views/clients/jobs/show.html.haml`

Client can change `work_hours` and `work_date` when confirming job completion.
The controller uses the new values to recalculate `work_amount_ore`. This is intentional
(client adjusts final hours) but there's zero UI hint that changing hours changes the
invoice amount. A client who doesn't notice the field could accidentally confirm
different hours than the shop set.

**Fix:** add a small note: "Changing hours will adjust the invoice amount."

Not an issue.
